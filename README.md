# Macacxyz INDUSTRIES | IRONHAND

Proyecto académico interactivo sobre la integración de sensores electrónicos y señales bioeléctricas en prótesis.
Siendo sincero parte del proyecto fue desarrollado con I.A, pero , tambien del mismo tienes implementaciones humanas mias y de codigo de libre uso de internet,  no quiero el credito de este trabajo y sinceramente cualquier individuo puede usarlos para otras presentaciones, trabajos,etc.

PD: Aparezco como autor como mero simbolismo, solamente como una forma de que yo recopile parte de trabajo mio, de la I.A, y de codigo abierto en internet

## Objetivo

Explorar cómo las señales electromiográficas (EMG) pueden utilizarse para interpretar la actividad muscular y controlar una prótesis electrónica.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- SVG

## Características

- Interfaz interactiva inspirada en Stark Industries. (Referencia a Iron Man)
- Simulación visual de señales bioeléctricas.
- Representación de una prótesis robótica.
- Diseño adaptable a diferentes pantallas.

## Ejecución

Abre `index.html` en un navegador web.
