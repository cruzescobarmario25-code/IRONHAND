# STARK INDUSTRIES | IRONHAND

Proyecto académico interactivo sobre la integración de sensores electrónicos y señales bioeléctricas en prótesis.

## Objetivo

Explorar cómo las señales electromiográficas (EMG) pueden utilizarse para interpretar la actividad muscular y controlar una prótesis electrónica.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- SVG

## Características

- Interfaz interactiva inspirada en Stark Industries.
- Simulación visual de señales bioeléctricas.
- Representación de una prótesis robótica.
- Diseño adaptable a diferentes pantallas.

## Ejecución

Abre `index.html` en un navegador web.
